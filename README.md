# KeenKids Thanksgiving Feast: Scratch lesson kit

A 48-minute Scratch lesson for KeenKids Enrichment (grades 1–2). Students make a catching game in which a Chef collects falling food for the feast, using events, motion, clones and a Score variable. Everything in `output/` is generated from the supplied starter project by a Node pipeline, which also builds the completed teacher project and checks that the deck teaches every block of it.

## Rebuild

```sh
cd src
npm ci
./build_all.sh   # zsh; regenerates the .sb3, runs gameplay tests, renders slides, builds the deck and docs
```

`src/browser.js` launches Playwright's `chromium_headless_shell-1254` from `~/Library/Caches/ms-playwright/` (the build matching `playwright-core` 1.65.1). Install it, or edit `browser.js` to point at another Chromium. The Chromium steps fail inside the Claude Code macOS sandbox, so run them outside it.
